# Currency Converter — Тестовое задание

Приложение представляет собой SPA на Vue 3 для конвертации валют. Реализованы две страницы и базовая маршрутизация с использованием Vue Router.

## 🔗 Демо

👉 [Посмотреть на GitHub Pages](https://rotainmos.github.io/currency-converter/)

## 📌 Функциональность

- Хедер с навигацией между страницами и выбором основной валюты (RUB, USD, EUR)
- Главная страница (`/`) — отображение курсов валют относительно выбранной основной валюты
- Страница конвертации (`/convert`) — интерактивная форма с двумя строками:
  - Каждая строка содержит Dropdown с выбором валюты и Input
  - Значения синхронизируются между полями в режиме реального времени
  - Конвертация с округлением до двух знаков

## ⚙️ Технологии

- Vue 3 + `<script setup>`
- TypeScript
- Vite
- Vue Router
- Pinia
- Tailwind CSS v4
- GitHub Actions (деплой на GitHub Pages)

## 🚀 Запуск локально

```bash

```
